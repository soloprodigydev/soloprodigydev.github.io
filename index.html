PROLARIS
VST INSTRUMENT / EFFECT PLUGIN

Set the Standard.

PROLARIS is an original VST plugin built to consolidate the best of what modern synthesis has to offer — spectral, wavetable, granular, and sampled sound design in a single instrument. Built for producers who don't want to context switch between five plugins to build one patch.
